# Senvolon Home Assistant Blueprints

Blueprints zu den How-tos im Senvolon-Blog: https://senvolon.de/blogs/wissen

| Blueprint | Zum Artikel |
| --- | --- |
| `automation/zisterne_platz_schaffen.yaml` | Die Zisterne als Regenrückhalt, Teil 3 der Zisternen-Reihe |
| `automation/zisterne_notbremse.yaml` | Die Zisterne als Regenrückhalt, Teil 3 der Zisternen-Reihe |

| `automation/heizen_nach_raumtemperatur.yaml` | Heizung nach Anwesenheit steuern: Heizen und Lüften mit dem Präsenzmelder |
| `automation/lueften_hinweis.yaml` | Heizung nach Anwesenheit steuern: Heizen und Lüften mit dem Präsenzmelder |
| `automation/lueften_taste.yaml` | Heizung nach Anwesenheit steuern: Heizen und Lüften mit dem Präsenzmelder |

Import: im Artikel auf „In Home Assistant importieren“ klicken oder unter
**Einstellungen → Automationen → Blueprints → Blueprint importieren** die Adresse der Datei eintragen.

Getestet mit Home Assistant 2026.9 (Zisterne) und 2026.10 (Heizen und Lüften).
